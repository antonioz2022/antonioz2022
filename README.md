# 🔬 Featured Projects

### 🧬 Predicting Mammalian Extinction Risk with Machine Learning
Machine learning project exploring whether biological and ecological traits can predict extinction risk in mammals.

The project integrates multiple scientific datasets:

- Pantheria (life history traits)
- EltonTraits (diet and ecological behavior)
- IUCN Red List (conservation status)

Key components:

- Data integration from multiple ecological datasets
- Feature engineering and preprocessing
- Logistic Regression and Random Forest models
- Model evaluation (ROC-AUC, confusion matrix, precision-recall)
- Feature importance analysis

Dataset:

- ~4,100 mammalian species  
- 40+ ecological traits

This project demonstrates a complete machine learning workflow applied to biodiversity science.
